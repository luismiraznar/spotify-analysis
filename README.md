🎵 Spotify Songs Popularity Analysis

Análisis de la popularidad de canciones en Spotify para descubrir qué factores influyen en el éxito musical.
El proyecto utiliza datos de miles de canciones y analiza patrones relacionados con la energía, el tempo, la valencia y otros atributos musicales.

📊 Tecnologías utilizadas

Python (pandas, matplotlib, seaborn)

Power BI

Jupyter Notebook

🧠 Principales objetivos

Analizar la distribución de la popularidad de las canciones.

Identificar las características más comunes de las canciones más escuchadas.

Comparar cómo varían las métricas entre géneros y años.

Explorar posibles correlaciones entre atributos musicales y éxito comercial.
